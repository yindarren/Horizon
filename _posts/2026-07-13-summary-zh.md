## [Claude Code 与 OpenCode 对比：分析显著的 Token 开销差异](https://systima.ai/blog/claude-code-vs-opencode-token-overhead) ⭐️ 7.0/10

一项对比研究发现，Claude Code 在处理提示词前会消耗约 33,000 个 Token，远高于 OpenCode 所需的 7,000 个。这种差异主要归因于 Claude Code 更庞大的系统提示词以及更激进的子代理编排策略。 对于管理 AI 代理预算的开发者来说，了解 Token 使用效率至关重要，因为低效的工具可能导致相同任务的成本高出 4 到 5 倍。这凸显了在成本敏感型开发中评估代理工作流的重要性。 研究指出，针对简单任务频繁调用工具和启动子代理会导致严重的“Token 通胀”。开发者需注意，由于不同代理框架管理上下文和编排的方式不同，即使是基础命令也可能产生高额开销。

hackernews · systima · 7月12日 18:25 · [社区讨论](https://news.ycombinator.com/item?id=48883275)

**背景**: AI 编程代理是与代码库交互以执行编辑文件或运行命令等任务的工具。代理框架（Agent Harness）作为基础设施，负责管理这些交互，包括系统提示词、工具定义和子代理编排。Token 开销是指模型在实际执行用户特定请求之前，为维护这些基础设施所消耗的 Token 数量。
