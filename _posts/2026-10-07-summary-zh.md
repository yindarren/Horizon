OpenAI 已将 Decisions API 推向公测，为高速、低成本的分类和决策任务提供了专门的接口。该 API 利用 'gpt-6-luna' 模型，根据预定义的选项或准则对输入内容进行评估。 此次发布标志着 OpenAI 在优化“系统一”（System One）任务方面的战略转变，这对构建高效的 AI 智能体和自动化工作流至关重要。通过提供比通用大模型更便宜、更快速的替代方案，OpenAI 正在分类市场中与专业开源模型展开直接竞争。 该 API 专为条件检查、从固定选项中选择以及对文本或图像进行评分等任务而设计。它优先考虑低延迟和成本效益，非常适合不需要完整生成能力、但对吞吐量要求较高的大规模智能体工作流。

**背景**: 在人工智能领域，“系统一”（System One）指的是快速、直觉化和自动化的处理过程，这与涉及较慢、深思熟虑的推理过程的“系统二”（System Two）形成对比。智能体工作流（Agentic workflows）是指 AI 模型作为智能体执行一系列任务以实现特定目标，而非仅仅生成单一回复的自动化流程。

## [谷歌发布 EmbeddingGemma 2：一款开源且轻量级的多模态嵌入模型](https://blog.google/innovation-and-ai/technology/developers-tools/embeddinggemma-2/) ⭐️ 8.0/10

谷歌发布了 EmbeddingGemma 2，这是一款旨在实现高效文本和图像向量化的开源轻量级模型。它为开发者提供了一种紧凑的解决方案，以低成本在本地执行多模态嵌入任务。 此次发布意义重大，因为它为开发者提供了一种高性能且采用 Apache 2.0 许可的替代方案，以取代专有的嵌入服务，从而帮助开发者避免供应商锁定并降低 RAG 和 AI 代理系统的运营成本。 该模型提供 2.7 亿参数的纯文本配置版本，以及 4.4 亿参数的文本加视觉版本。这些参数规模使其非常适合在资源受限的环境中部署。

hackernews · ilreb · 10月6日 16:03 · [社区讨论](https://news.ycombinator.com/item?id=49980487)

**背景**: 嵌入模型将文本和图像等非结构化数据转换为数值向量，使 AI 系统能够通过计算这些向量之间的距离来执行语义搜索。多模态模型通过将不同类型的数据映射到共享的向量空间来扩展此功能，从而实现跨模态检索，例如使用文本查询来搜索图像。
